# Дмитрий Толкачёв

**Business Analyst | IT & E-commerce | AI-assisted automation**

Бизнес-аналитик с техническим бэкграундом: QA → Frontend → Business Analysis.

Работаю с требованиями, бизнес-процессами и документацией, использую BPMN, UML, User Stories и Use Cases. В задачах по автоматизации использую Claude, Codex и ChatGPT: формулирую требования и технические задачи для AI, исследую предметную область и итеративно уточняю результат.

## 🧩 Что умею

- Анализировать бизнес-процессы и выявлять точки для улучшения и автоматизации
- Собирать и структурировать требования
- Моделировать AS-IS / TO-BE в BPMN
- Разрабатывать User Stories, Use Cases и критерии приёмки
- Работать с бизнес-правилами, интеграциями и исключительными сценариями
- Анализировать данные и справочники, прорабатывать правила качества данных
- Использовать AI для прототипирования решений и автоматизации рутинных задач
